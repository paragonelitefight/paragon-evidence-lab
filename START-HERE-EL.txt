ΣΗΜΑΝΤΙΚΟ
Αυτό ΔΕΝ είναι ολοκληρωμένο/πιστοποιημένο Ultimate σύστημα.
Είναι το προηγούμενο ενιαίο σύστημα 0.11 ΑΝΕΠΑΦΟ μαζί με τη νέα συντονισμένη διαδικασία εκτέλεσης των εκκρεμών υπολογισμών και ελέγχων. Δεν δημιουργήθηκε νέος Worker και δεν δημοσιεύτηκε τίποτα.
Δεν βαφτίζουμε τις νέες οδηγίες/πηγές επιτυχημένες εκτελέσεις.

ΤΙ ΠΡΟΣΤΕΘΗΚΕ
acceptance/core.mjs: δύο ανακατασκευές Worker και σύγκριση bytes, syntax/import/route/PDF smoke checks, έλεγχος διατήρησης αρχικού timestamp αρχείου/receipt, ML-DSA65 sign/verify/αλλοίωση, τοπική επαλήθευση WBA-candidate signature/αλλοίωσης διαδρομής, στενός Checkout-JWT έλεγχος/λήξη/λάθος issuer/hash/SD-JWT απόρριψη, παλιός συνθετικός PIR έλεγχος.
acceptance/research.sh: πραγματική εντολή TLC στο πεπερασμένο μοντέλο, λήψη/κατασκευή OpenFHE 1.4.1 και εκτέλεση encrypted AND.
acceptance/zk.mjs: υποψήφια παραγωγή/επαλήθευση ZK απόδειξης συνθετικού ορίου ωρών, απόρριψη μη έγκυρων εισόδων και αλλοιωμένης απόδειξης.
.github/workflows/coordinated-acceptance.yml: ΜΙΑ χειροκίνητη εκκίνηση, core + τρεις ερευνητικές εκτελέσεις με ξεχωριστά αποτελέσματα και τελικό gate.

ΚΑΤΑΣΤΑΣΗ ΠΑΡΑΔΟΣΗΣ
Τα νέα scripts/workflow ΔΕΝ εκτελέστηκαν εδώ: το περιβάλλον του βοηθού δεν παρέχει Node, Java ή CMake. Η παρουσία κώδικα δεν αποδεικνύει λειτουργία. Τα εξωτερικά toolchains/API δεν έχουν ακόμη γίνει αποδεκτά μέσω πραγματικής εκτέλεσης. Αν αποτύχει λήψη, εγκατάσταση, API ή test, η αντίστοιχη εργασία αποτυγχάνει. Δεν μετατρέπουμε failure σε success.
Το προηγούμενο πράσινο workflow ΔΕΝ καλύπτει αυτές τις νέες δοκιμές.
Τα test αποτελέσματα δεν εισάγονται αυτόματα στον Worker ως δημόσιες βεβαιώσεις.

ΑΣΦΑΛΕΙΑ/ΚΟΣΤΟΣ
Τα screenshots του ιδιοκτήτη έδειξαν GitHub Free και 5 budgets $0 με Usage blocked. Διατηρήστε τα ανέπαφα.
Χρησιμοποιείται μόνο standard ubuntu-24.04 σε ΥΠΑΡΧΟΝ ΔΗΜΟΣΙΟ repository.
Μόνο workflow_dispatch: κανένα push trigger/cron/αυτόματο deploy.
Read-only repository permissions, checkout χωρίς αποθήκευση credentials.
Χωρίς secrets/κάρτες/πληρωμές/customer data/ιδιωτικά PDF.
Χωρίς artifact uploads/cache/Codespaces/paid runners.
Χρονικά όρια: core8λεπτά, ερευνητική εργασία30λεπτά, summary2λεπτά.
Καμία καθολική εγγύηση δωρεάν υπηρεσιών: αν κάποια διαδρομή απαιτήσει χρήματα, ΣΤΑΜΑΤΑΜΕ.
Οι third-party εκδόσεις είναι συγκεκριμένες, αλλά δεν υπάρχει πλήρες offline-vendored κλείδωμα όλων των μεταβατικών εξαρτήσεων/npm ούτε ανεξάρτητα επαληθευμένο binary provenance. Τα καταγεγραμμένα hashes δεν είναι από μόνα τους πιστοποίηση upstream.

ΜΙΑ ΣΥΝΤΟΝΙΣΜΕΝΗ ΕΓΚΑΤΑΣΤΑΣΗ ΠΗΓΩΝ, ΟΧΙ WORKER
1. Αποσυμπίεση ZIP.
2. Στο υπάρχον paragonelitefight/paragon-evidence-lab, ανέβασμα των ΠΕΡΙΕΧΟΜΕΝΩΝ της ρίζας. Όχι το ZIP ούτε εξωτερικό φάκελο. Διατήρηση υπάρχοντος README.md και παλιού manual workflow.
3. Συμπεριλάβετε τον κρυφό φάκελο .github. Αν το upload δεν τον περιλαμβάνει: Add file > Create new file, όνομα .github/workflows/coordinated-acceptance.yml, επικόλληση ΟΛΟΥ του κειμένου από το ομώνυμο αρχείο του ZIP. Αυτό είναι ξεχωριστή αποθήκευση του workflow, όχι νέο repository.
4. Commit στο main. ΜΗΝ κάνετε Cloudflare deployment.
5. Actions > Coordinated isolated evidence acceptance > Run workflow > main > Run workflow.
6. Επιστρέψτε το συνολικό αποτέλεσμα ή το πρώτο failed step. Δεν χρειάζεται να τρέξετε ξανά το παλιό workflow. Δεν αυξάνουμε budget για να παρακάμψουμε μπλοκάρισμα.

ΤΙ ΠΑΡΑΜΕΝΕΙ ΕΚΤΟΣ/ΑΝΟΛΟΚΛΗΡΩΤΟ
Πλήρες ANP με authenticated descriptions/DID binding/interop.
Πλήρες AP2 με SD-JWT, holder binding, delegation, mandates/constraints/receipts. Καμία πραγματική αγορά ή πληρωμή.
Ενεργή καταχώριση Web Bot Auth, εισερχόμενη επαλήθευση/anti-replay/abuse/αποδοχή από τρίτο.
TEE: καμία εγκεκριμένη κατάλληλη δωρεάν υποδομή, παραμένει κλειστό.
Πραγματικά ανεξάρτητοι μη συνεργαζόμενοι PIR servers.
Ανεξάρτητη αναπαραγωγή Worker από άλλον φορέα. Same-job identical bytes != ανεξάρτητη αναπαραγωγή.
Πραγματικός browser/Cloudflare/runtime/security έλεγχος. Node smoke tests != Cloudflare production acceptance.
Τελική Bitcoin επαλήθευση αρχικού OTS receipt. Το αρχείο διατηρείται ακριβώς, δεν ξαναστέλνουμε timestamp. Η χθεσινή επιθεώρηση είναι ιστορική, όχι σημερινή ένδειξη.
Αυθεντικοποιημένα δεδομένα DHL/Shopify/μητρώου/υπογραφών PDF. Hash/signature δεν πιστοποιεί την αλήθεια μιας δήλωσης.

ΓΙΑΤΙ Ο WORKER ΜΕΝΕΙ 0.11
Η νέα εργασία είναι υποδομή εκτέλεσης/αποδοχής, όχι ψεύτικη έκδοση με περισσότερες ετικέτες. Ο παλιός ενιαίος κώδικας δεν τροποποιείται ή εγκαθίσταται μέχρι να έχουμε πραγματικά αποτελέσματα και να διορθωθούν τυχόν σφάλματα.
Όλα τα πρωτότυπα εταιρικά/προσωπικά έγγραφα παραμένουν ιδιωτικά και δεν περιλαμβάνονται.
Όλες οι υπάρχουσες vendor άδειες/ειδοποιήσεις διατηρούνται. Καμία νέα γενική άδεια στο έργο του ιδιοκτήτη.
